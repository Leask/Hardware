# Bathroom Soap Box

Wall-mounted soap dish prototype for bathroom use.

## Files

- `Bathroom Soap Box - print mm.stl`: slicer-ready mesh in millimeters.
- `Bathroom Soap Box - blender.obj`: mesh for editing in Blender or other tools.
- `Bathroom Soap Box.blend`: editable Blender scene with the printable model.
- `generate_soap_box.py`: parametric Blender generator.
- `Bathroom Soap Box preview.png`: angled preview.
- `Bathroom Soap Box top preview.png`: top preview showing drain slots.

## Current Dimensions

- Overall printable part: 120.0 x 88.95 x 70.0 mm.
- Usable tray area: about 113 x 82 mm.
- Base thickness: 3.2 mm.
- Side wall height: 25.5 mm.
- Front lip height: 15.5 mm.
- Back plate height: 70.0 mm.
- Drainage: five rounded slots, 6 x 52 mm.
- Mounting: two closed keyhole slots, 70 mm center-to-center.

## Print Notes

- Suggested material: PETG or ASA for humid bathroom use.
- Print orientation: tray base flat on the build plate.
- Supports: none expected.
- Nozzle/profile: 0.4 mm nozzle, 0.2 mm layer height is a good first pass.
- Strength: 4 walls/perimeters and 20-30% infill.
- Install: use stainless screws or waterproof adhesive pads; avoid trapping water
  behind the back plate.
